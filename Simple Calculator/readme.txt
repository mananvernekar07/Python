# Python Calculator

A simple command-line calculator built with Python. This project allows users to enter two integers and select an arithmetic operator to perform a calculation.

## Features

* Addition (`+`)
* Subtraction (`-`)
* Multiplication (`*`)
* Modulus (`%`)
* Exponentiation (`**`)
* Handles invalid operators with an error message

## How It Works

The program:

1. Takes the first number as input.
2. Takes an arithmetic operator from the user.
3. Takes the second number as input.
4. Performs the selected operation.
5. Displays the result.

## Example

```text
Enter first number: 10
Enter operator(+,-,*,%,**): *
Enter second number: 5
Answer: 50
```

## Requirements

* Python 3.x

## How to Run

Save the code in a file such as `calculator.py`, then run:

```bash
python calculator.py
```

## Project Purpose

This project is designed for beginners to practice Python fundamentals, including user input, conditional statements (`if`, `elif`, `else`), arithmetic operators, and basic console output.
